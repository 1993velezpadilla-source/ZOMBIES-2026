# Xziel Zombies — Roblox prototype

This is a new Roblox project, separate from the Luanti APK. It is built with Luau and Rojo. The source and placeholder parts are original: there are **no COD4 models or sounds**.

The GitHub Actions job compiles an RBXLX place file. **It does not publish or create a Roblox game**.

To test on a Pixel Fold, first create a Roblox experience/place owned by @Xziel93, then obtain Universe ID and Place ID. Roblox's place publishing API updates an existing place. Later, use a restricted Open Cloud API key as a GitHub secret; never place keys in this repository or paste them into chat.

https://create.roblox.com/docs/cloud/guides/usage-place-publishing
